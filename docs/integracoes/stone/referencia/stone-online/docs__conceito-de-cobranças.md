# Conceito de cobranças

# Conceito

A cobrança é o fundamento central de qualquer pagamento. Ela representa a entidade principal para a criação de transações com a nossa adquirente e serve como base para todas as operações realizadas junto aos meios de pagamento.

A partir da cobrança, é possível executar diversas ações, como autorizar, capturar, cancelar e consultar transações, garantindo eficiência e segurança em todo o processo financeiro.

Compreender a importância da cobrança é essencial para otimizar a experiência do cliente e assegurar a fluidez das transações.

| Status     | Descrição                      |
| :--------- | :----------------------------- |
| authorized | Autorizada pendente de captura |
| Declined   | Não autorizada                 |
