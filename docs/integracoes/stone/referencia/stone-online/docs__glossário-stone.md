# Glossário Stone

Para entender melhor os termos utilizados em nossa documentação, aqui estão a definição de alguns conceitos da Stone.

<br />

| Termo         | Definição                                                                                                                                                                                                                                            |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| id            | É o código de identificação da transação gerado pela Stone                                                                                                                                                                                           |
| initiator\_id | É o código de identificação da transação gerado pelo ponto de interação. **Deve ser formatado seguindo a seguinte regra: nnnnnnddmmyyyyHHMMSS. Sendo que nnnnnn = número sequencial gerado pelo sistema que se comunica com o host Stone (VALIDAR)** |
| StoneCode     | É o código do estabelecimento dentro da Stone. Esse valor é único                                                                                                                                                                                    |
| DCC           | Conversão dinâmica de moeda                                                                                                                                                                                                                          |
| SaaS          | Software as a Service                                                                                                                                                                                                                                |
| E-wallets     | Carteiras digitais                                                                                                                                                                                                                                   |
| MIT           | Merchant Initiated Transaction                                                                                                                                                                                                                       |
| CIT           | Customer Initiated Transaction                                                                                                                                                                                                                       |
| PCI DSS       | Payment Card Industry Data Security Standard                                                                                                                                                                                                         |
| EMV           | Payment Card Industry Data Security Standard                                                                                                                                                                                                         |
| Magstrip      | Magnetic stripe transaction                                                                                                                                                                                                                          |
| Contacless    | Pagamento por aproximação                                                                                                                                                                                                                            |
| Pin Online    | A senha do cartão é verificada junto ao banco emissor, através de conexão online no momento da transação                                                                                                                                             |
| Pin Offline   | A senha do cartão é verificada pelo próprio chip do cartão, sem a necessidade de comunicação imediata com o banco                                                                                                                                    |
