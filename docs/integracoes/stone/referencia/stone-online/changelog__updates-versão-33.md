# Updates Versão 3.3

Aqui estão as novidades do Stone Online versão 3.3! :up:

Reorganizamos algumas páginas para adicionar uma nova aba de ajustes que servirá para indicarmos mudanças nos nossos serviços que poderão te impactar.

Adicionamos 2 novas páginas com informações importantes para a sua integração na nova aba de ajustes:

* Informações importantes sobre o envio de tipos de transação para transações CITs (Cardholder Initiated Transaction) e MITs (Merchant Initiated Transaction): [Envio de indicadores de transações](https://online.stone.com.br/v3.3/reference/envio-de-indicadores-de-transa%C3%A7%C3%A3o)
* Novas informações sobre o novo modelo de retorno dos limites de retentativas: [Limite de retentativas](https://online.stone.com.br/v3.3/reference/limite-de-retentativas-1)

Caso tenha alguma dúvida basta enviar no nosso [fórum](https://online.stone.com.br/v3.3/discuss)!
