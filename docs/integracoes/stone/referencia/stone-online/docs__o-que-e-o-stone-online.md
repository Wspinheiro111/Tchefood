# O que é a API Stone Online?

## Introdução

"O Stone Online" é a API transacional da Stone que possui a função de autorizar, capturar, cancelar e consultar transações, para utilização em plataformas de vendas online (e-commerce) e no mundo físico.

Esta API é indicada para empresas que já possuem na sua estrutura serviços como: antifraude, multimeios de pagamento, recorrência, etc., e necessitam **apenas** dos serviços transacionais base já mencionados.

Para parceiros que desejam, mas ainda não possuem estes serviços, a API mais indicada é a da [Pagar.me](https://docs.pagar.me/docs).

Caso queira ir direto às informações técnicas, acesse a [documentação da nossa API](https://online.stone.com.br/reference/overview-da-api).
