# Updates Versão 3.4

Aqui estão as novidades do Stone Online versão 3.4! :green-heart:

Trouxemos uma mudanças importante nas páginas de 3DS:

Agora os valores aceitos para as versões de 3DS que serão enviadas na tag **`<TdScreVrsn>`** deixarão de ser VRS1 e VRS2 e deverão ser enviados apenas com variantes da VRS2:

| Valor na tag <TdScreVrsn> | Versão de 3DS |
| :------------------------ | :------------ |
| VRS21                     | 3D Secure 2.1 |
| VRS22                     | 3D Secure 2.2 |
| VRS23                     | 3D Secure 2.3 |
| VRS24                     | 3D Secure 2.4 |
| VRS25                     | 3D Secure 2.5 |
| VRS26                     | 3D Secure 2.6 |
| VRS27                     | 3D Secure 2.7 |
| VRS28                     | 3D Secure 2.8 |
| VRS29                     | 3D Secure 2.9 |

Para mais informações, acesse nossa página de [3DS](https://online.stone.com.br/reference/exemplos-de-3ds).

Caso tenha alguma dúvida basta enviar no nosso [fórum](https://online.stone.com.br/v3.3/discuss)!
