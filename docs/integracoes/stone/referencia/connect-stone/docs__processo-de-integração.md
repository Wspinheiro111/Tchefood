# Processo de integração

Para se integrar com a API do Connect Stone, você precisa passar por três etapas

## 1 - Integração

Você receberá acesso a Dashboard da Pagar.me para realizar os testes transacionais, com uma account previamente criada. Esses dados serão enviados para sua equipe no momento do setup da conta, nosso time acompanhará todo o processo de integração. Para receber uma credencial de integração é necessário se cadastrar no nosso programa de parcerias. Cadastre-se [aqui](https://connect-stone.stone.com.br/docs/evolua-ao-nosso-lado).

## 2 - Homologação

Após finalizar o desenvolvimento da integração, você receberá um roteiro de testes que deve ser preenchido e enviado para que possamos validar sua integração.\
Esse é um processo de teste, que tem como objetivo validar se todos os casos transacionais estão sendo executados com sucesso para que você não tenha problemas ao colocar sua solução em produção.\
**Nós acompanharemos todo o processo com você.**

## 3 - Produção

Ao final da homologação, você receberá o nosso OK para ir para produção. Neste momento o Gerente Comercial Stone responsável por sua parceria conosco irá disponibilizar o manual do parceiro contendo todas as informações necessárias para que sua operação cresça com a gente.

Caso já tenha se cadastrado no nosso programa de parcerias, entre em contato com seu Gerente Comercial na Stone ou canal comercial que iniciou a comunicação.\
Caso ainda não tenha se cadastrado, você consegue fazê-lo [aqui](https://connect-stone.stone.com.br/docs/evolua-ao-nosso-lado).
